> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. The visual direction is selected; implementation is isolated from the user's working checkout.

**Goal:** Сделать настройки и общие элементы интерфейса компактными, понятными и согласованными между Chrome/Firefox, сохранив узнаваемый вид Minimal Tab.
