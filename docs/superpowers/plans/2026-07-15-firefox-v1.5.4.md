# Firefox v1.5.4 Build Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Produce a Firefox Add-ons-ready Minimal New Tab v1.5.4 ZIP while preserving the existing Chrome archive byte-for-byte.

**Architecture:** Keep one shared application source, extract Chrome favicon lookup into an overridable provider, and add a minimal Promise-based WebExtension API selector. A deterministic Firefox builder copies an explicit allowlist, overlays the Firefox manifest and no-network favicon provider, and creates a root-level ZIP.

**Tech Stack:** Manifest V3, vanilla JavaScript ES modules, Node.js built-in test runner and filesystem APIs, `/usr/bin/zip`, Mozilla `web-ext`.
