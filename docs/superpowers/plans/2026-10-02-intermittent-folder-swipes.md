# Reliable Fast Folder Swipes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Execute sequentially; diagnostic evidence gates the choice of fix.

**Goal:** Устранить периодические пропуски отдельных свайпов, сохранив быстрое переключение без повторной загрузки карточек.

**Architecture:** Сначала сопоставить реальный пропущенный жест с маршрутом wheel-событий, решением распознавателя и сменой папки. Затем исправить только доказанную причину в существующем распознавателе или его UI-подключении. Нового слоя хранения, анимации, очереди переходов и настройки чувствительности не добавлять.

**Tech Stack:** JavaScript ES modules, DOM wheel events, Node test runner, Playwright Chromium/Firefox.

**Spec:** `docs/folder-swipes-2026-09-22.md`, раздел «Open manual finding»; `docs/superpowers/plans/2026-09-22-next-release-roadmap.md`, раздел «Быстрое переключение папок свайпом».

## Review Focus

1. Следующий отдельный жест поверх инерции предыдущего: не требовать тапа или искусственно долгой паузы и не принимать саму инерцию за новый жест.
2. Неподвижный указатель над карточкой, которая исчезает при смене папки: проверить доставку событий, а не только числовые дельты.
3. Вертикальная/диагональная прокрутка и движение от шапки к карточкам: не захватывать обычный скролл и не оставлять блокировку для будущих независимых жестов.
4. Открытие/закрытие формы, фокус и drag: подавлять жест в запрещённом контексте, но не последующие разрешённые жесты.
5. Медленное/ошибочное сохранение и смена направления: не ждать записи, не откатывать видимую папку поздним результатом и не возрождать удалённые карточки.
