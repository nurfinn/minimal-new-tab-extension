# Firefox v1.5.5 store copy

## English — What’s new

Site icons are now more reliable in Firefox. Popular services use lightweight icons included with the extension, while every other site keeps a clean letter fallback. You can optionally enable loading missing icons in Settings; it is off by default.

## English — Privacy note

Popular site icons are stored inside the extension and require no network request. If you enable “Load missing site icons,” only the saved site’s domain is sent to that site and, if needed, to Google’s favicon service. Full links, paths, document IDs, titles, and account details are not sent. You can turn this off at any time in Settings or Firefox’s Permissions and data panel.

## Русский — Что нового

Иконки сайтов в Firefox стали надёжнее. Для популярных сервисов используются лёгкие иконки внутри расширения, а для остальных сайтов всегда остаётся аккуратная буква. При желании можно включить загрузку недостающих иконок в Настройках; по умолчанию она выключена.

## Русский — Конфиденциальность

Иконки популярных сайтов хранятся внутри расширения и не требуют сетевых запросов. Если включить «Загружать недостающие иконки», передаётся только домен сохранённого сайта — самому сайту и, при необходимости, сервису фавиконов Google. Полные ссылки, пути, ID документов, названия и данные аккаунта не отправляются. Настройку можно отключить в любой момент в расширении или в разделе разрешений Firefox.
