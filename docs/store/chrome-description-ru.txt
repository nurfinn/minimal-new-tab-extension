Minimal New Tab — минималистичная новая вкладка с быстрым доступом к любимым сайтам. Соберите свою стартовую страницу: удобная экспресс-панель, папки, эмодзи и собственный фон — без лишних виджетов.

Сайты в удобном порядке

- Добавляйте, редактируйте и меняйте порядок сайтов.
- Собирайте сайты в папки и расставляйте папки так, как вам удобно.
- Переключайтесь между папками горизонтальными свайпами на тачпаде.
- Скройте «Все» без удаления сайтов. Сайты, не распределённые по папкам, останутся доступны.

Настройте под себя

- Оставьте иконки сайтов или выберите эмодзи из встроенного каталога с поиском, категориями и вариантами оттенка кожи. Каталог работает без интернета.
- Добавьте своё фоновое изображение и настройте цвет и непрозрачность подложки.
- Используйте горячие клавиши: A — добавить сайт, F — открыть папки, S — открыть настройки. Их можно отключить.
- Интерфейс автоматически выбирает русский или английский язык по настройкам браузера.

Перенос и резервные копии

Экспортируйте и импортируйте сайты, папки, их порядок и выбранные эмодзи через JSON-файл для переноса в другой браузер с установленным Minimal Tab. Пользовательские фоновые изображения остаются в текущем браузере и не входят в резервную копию.

Если синхронизация расширений Chrome включена, сайты и небольшие настройки могут синхронизироваться между установками Chrome с одним аккаунтом Google. Chrome и Firefox используют разные системы синхронизации — для переноса между ними нужны экспорт и импорт.

Приватность и разрешения

Без отдельной регистрации, рекламы и аналитики. Расширение не собирает историю браузера и не запрашивает доступ ко всем сайтам.

Нужны только два разрешения:

- Storage — для сохранения сайтов, папок, настроек и локального фона.
- Favicon — для отображения иконок сохранённых сайтов.

Новое в версии 1.7

- Эмодзи вместо иконки сайта: встроенный каталог с поиском, категориями и вариантами оттенка кожи.
- Переключение папок горизонтальным свайпом на тачпаде.
- Возможность скрыть «Все» в управлении папками — без удаления сайтов.
- Обновлённые настройки и более аккуратные элементы форм.
- Более мягкая иконка расширения с привычной формой.
- Резервные копии JSON теперь сохраняют выбранные эмодзи.
- Уведомление о готовом обновлении расширения в Chrome с кнопками «Обновить» и «Позже».
- Более надёжное сохранение настроек и безопасная замена пользовательского фона.

Совместимость резервных копий

Перед импортом новой резервной копии обновите Minimal Tab в принимающем браузере. Версии 1.6 и более ранние не поддерживают новый формат. Старые резервные копии по-прежнему можно импортировать. Обои остаются в своём браузере и не входят в JSON.

Внешний вид и доступность эмодзи зависят от операционной системы.
