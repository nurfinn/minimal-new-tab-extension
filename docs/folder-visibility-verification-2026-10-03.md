# Видимость «Все» — 3 октября 2026

Согласован второй макет: компактная галочка «Показывать «Все»» слева в нижней строке окна «Папки», «Готово» справа. Первый вариант с заметным верхним блоком отклонён. Общие настройки, видимость пользовательских папок и редизайн окна не входят в задачу.

## Поведение

- По умолчанию «Все» видна. Отключение скрывает только вкладку и исключает её из свайпов; ссылки, их порядок, папки, emoji и фон не удаляются и не перемещаются.
- Выбранная пользовательская папка сохраняется. Если скрывается выбранная «Все», открывается первая пользовательская папка.
- При наличии сайтов без папки появляется «Без папки» / Unfiled в конце навигации. Это гарантирует доступ к сайтам, включая оставшиеся после удаления папки. Назначение папки, редактирование и перенос работают как прежде.
- Если пользовательских папок нет, «Все» остаётся видимой, галочка отмечена и недоступна; подсказка предлагает сначала создать папку. Удаление последней папки возвращает «Все».
- Изменение применяется сразу. Пока идёт сохранение, галочка недоступна. При ошибке возвращается подтверждённое значение и показывается существующая ошибка в окне.
- Параметр `preferences.showAllFolder: false` необязателен и записывается через прежний sync-service. Отсутствующее или повреждённое значение означает «показывать», без удаления снимка. Алгоритм чанков, поколений и восстановления не менялся.
- JSON по-прежнему переносит сайты и папки, а не настройку видимости: импорт сохраняет текущий выбор целевого браузера. Старый клиент 1.6 этого параметра не знает; его последующая запись может снова показать «Все». Синхронизация между разными версиями не сертифицирована.
